# Pro-code Contoso Agent Lab

This folder contains the code-first version of the Contoso complaint-resolution lab.

Use [`START-HERE.md`](./START-HERE.md) as the implementation guide.

## Implementation strategy

- Keep the same iterations as the portal lab: 1, 2, and 3.
- Keep each agent prompt in `prompts/`.
- Keep typed JSON contracts in `src/contoso_lab/models.py`.
- Keep orchestration code separated by iteration.
- Keep Data Pack files in `../data/`.

## Status

This is a skeleton. The files mark where to add Microsoft Agent Framework code after you confirm the current SDK APIs for your Foundry-hosted agents.
